# GuidCreator.Desktop

Avalonia desktop utility for generating uppercase RFC 4122 version 4 GUIDs.

## Behavior

- The window has a fixed size.
- The GUID starts empty.
- `Create` generates a new uppercase GUID.
- `Copy` copies the current GUID to the system clipboard and is disabled while no GUID exists.
- The solution and project target .NET 8 x64.
